# Leitura recomendada

Livros de base por trás de decisões reais deste padrão — não uma lista
genérica de "boa leitura", cada um tem página própria com os assuntos
principais e onde exatamente ele aparece citado ao longo da wiki (em
"Onde aparece no padrão frontend", em cada página de conceito). A escolha
prioriza fundamentos que envelhecem bem (arquitetura, dado distribuído,
qualidade de código) sobre livro específico de uma lib/framework, que
fica desatualizado rápido.
