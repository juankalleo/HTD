# Componentes reutilizáveis

Building blocks de UI compartilhados (`shared/ui`, `shared/forms`, `shared/hooks`),
fora de qualquer feature específica. Cada um tem sua página:

- [Botões](/padrao-frontend/componentes/botoes) — `Button` tipado (cva) e `buttonVariants`.
- [Busca](/padrao-frontend/componentes/busca) — `SearchInput` com debounce de 350ms.
- [Filtros](/padrao-frontend/componentes/filtros) — `FilterSelect` + convenção Ransack/Pagy (`q[...]`, `pagy`).
- [Tipos (TypeScript)](/padrao-frontend/componentes/tipos) — de onde vêm os tipos (Zod, `types/index.ts`, `services/*`).

Outros componentes compartilhados já documentados em outras seções:
[Tabelas](/padrao-frontend/tabelas) (`DataTable`, `Pagination`, `ResultsCount`),
[Estilos](/padrao-frontend/estilos) (`Modal`, `Select`, paginação visual) e
[Formulários](/padrao-frontend/formularios).
